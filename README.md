# MY-WORKSPACE

## Workspace Mail AI Task Sync

An AI-powered workspace integration assistant that summarizes emails, manages calendar events & tasks, compiles meet notes, and synchronizes Google Workspace apps including Google Docs, Sheets, Slides, Forms, and Keep.

### Key Features
- **AI Mail Analysis**: Automatic email summarizing and categorization using Gemini.
- **Task & Calendar Sync**: Seamless creation of tasks and calendar event scheduling based on inbox activity.
- **Meeting Notes Intelligence**: High-impact compiling and extraction of action items from meetings.
- **Cross-App Sync**: Dynamic synchronization Across Google Workspace tools.

---

### UI Settings & Export
If you are looking to export this repository to GitHub or download the source code:
1. Locate the **Settings** or **Export** option in the top right-hand side toolbar of Google AI Studio.
2. Select **Export to GitHub** or **Download ZIP**.
3. Authorize your GitHub account and sync with your repository: `https://github.com/JathinBhargav/MY-WORKSPACE.git`.
